# mini-tasks

Projeto para o cadastro de tarefas, repetitivas ou pontuais, que conta com um sistema de notificação.

## Descrição:
A ideia desse projeto é criar um pequeno programa em Python que as pessoas possam baixar e rodar na própria máquina.
Ele serve para o cadastro de tarefas, que podem ser tanto repetitivas como pontuais, que conta com com um sistema de notificações.
Para as tarefas repetitivas, a pessoa pode escolher notificações que são disparadas a cada x tempo ou que aconteção em momentos específicos.
Já para as tarefas pontuais, essas notificações vão ser em um dia e horário específico, ou por intervalos de tempo informando quanto tempo ainda falta para a pessoa entregar a tarefa.
Esse sistema de notificações também vai contar com a opção de marcar a tarefa como concluída ou adiar a notificação por x tempo.
